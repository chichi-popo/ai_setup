## 색
| 역할 | HEX | 비중·용도 |
| --- | --- | --- |
| primary | [#0F2A4A] | 60~70%: 제목, 표지·마무리 배경, 주요 도형, Word 제목·표지 |
| secondary | [#5B7FA6] | 20~30%: 강조 텍스트, 보조 도형, Word 부제목·표 헤더 배경 |
| accent | [#F2A93B] | 5~10%: 그래프 강조, 숫자 콜아웃, CTA, Word 콜아웃 |
| background | #FFFFFF | 본문 슬라이드(라이트) |
| background-dark | [#0F2A4A] | 표지·마무리 슬라이드(다크) |
| text | #333333 | 라이트 배경 본문 |
| text-on-dark | #F5F5F5 | 다크 배경 본문 |
- 색은 primary·secondary·accent 3색 안에서, 한 색이 우세하게. 차트·표 색도 이 팔레트에서만 고른다.
- 슬라이드는 표지·마무리 다크, 본문 라이트의 샌드위치 구조가 기본(다크 일관 유지도 가능, 임의 혼용 금지).
- pptxgenjs 등에 넘길 때 HEX는 `#` 없이 6자리. 8자리(투명도) 금지.

## 글꼴
| 요소 | 글꼴 | 크기 | 굵기 |
| --- | --- | --- | --- |
| PPT 슬라이드 제목 | [Cambria] (대안 Bookman Old Style, Century Schoolbook) | 36~44pt | Bold |
| PPT 섹션·소제목 | [Cambria] | 20~24pt | Bold |
| PPT 본문 | [Calibri] (대안 Arial) | 14~16pt | Regular |
| PPT 캡션·출처·각주 | [Calibri] | 10~12pt | Regular, 회색 |
| PPT 강조 숫자 | [Cambria] | 60~72pt | Bold |
| Word Title(표지) | [Cambria] | 26~32pt | Bold |
| Word Heading 1 | [Cambria] | 18~20pt | Bold |
| Word Heading 2 | [Calibri] | 14~15pt | Bold |
| Word 본문(Normal) | [Calibri] | 10.5~11pt | Regular |
| Word Caption·각주 | [Calibri] | 9pt | Regular, 회색 |
- 제목 세리프 + 본문 산세리프 페어링이 기본. 한글 글꼴은 [맑은 고딕](본문)·[맑은 고딕 또는 회사 지정](제목) — 회사 양식이 정해지면 바꾼다.
- 제목, 섹션 헤더, 인라인 라벨("구분:", "담당:")은 Bold.

## 여백·격자
- PPT 캔버스: 와이드 13.33" x 7.5"(`LAYOUT_WIDE`). 슬라이드를 추가하기 전에 크기부터 지정.
- PPT 여백 최소 0.5", 콘텐츠 블록 간격 0.3~0.5". 제목·footer·여백은 하나의 마스터(공통 격자)를 따른다.
- Word 여백 상하좌우 1"(표지·섹션 구분 페이지는 예외), 단락 뒤 6~8pt, 줄 간격 1.15~1.5.
- Word 헤더·푸터: 페이지 번호 + 문서명·버전 고정. 표지: 제목, 부제, 작성일, 버전, (필요 시) 작성자·대상 독자.

## 레이아웃 (PPT)
- 슬라이드마다 시각 요소(이미지, 차트, 아이콘, 도형) 1개 이상. 같은 유형 슬라이드는 같은 패턴.
- 패턴: 2단(좌 텍스트 / 우 이미지·아이콘), 아이콘+텍스트 행 반복, 2x2·2x3 격자, 하프블리드 이미지+텍스트, 표·차트 전용(제목+편집 가능한 표·차트+캡션).
- 도형: 사각형 대신 둥근 모서리 사각형(모서리 반경 = 높이의 약 8~12%). 순수 사각형은 전체 배경 블록·이미지 마스크 같은 예외에만.
- 아이콘은 원형 배경 안(accent 원 + 흰 아이콘). 강조선은 얇은 선 또는 accent 테두리, 상단·좌측 두꺼운 컬러 바 반복 금지.
- 모티프 하나(예: 둥근 이미지 프레임 + 원형 아이콘)를 정하면 전체에서 반복.
- 그림자 offset은 0 이상(위쪽 그림자는 angle 270 + 양수 offset).

## 표·차트
- 차트·표는 편집 가능한 네이티브 객체(PPT `addChart`·`addTable`, Word 표). 이미지로 넣지 않는다(원본이 스캔·이미지면 예외, 사용자에게 알림).
- 도식화 때 원본의 값·라벨·항목·각주·단위가 빠짐없이 들어갔는지 대조. 부득이 뺀 것은 무엇을 왜 뺐는지 보고하고 대안 제시.
- Word 표: 헤더 행은 secondary 배경 + 흰색 굵은 글자, 숫자 우측·텍스트 좌측 정렬. 이미지는 본문 폭 안, 캡션(출처·설명) 필수.

## Word 스타일
- 내장 스타일(Title, Heading 1·2, Normal, Caption)을 수정해서 쓰고 문단마다 글꼴을 직접 지정하지 않는다(목차 자동 생성 호환).
- 목차는 Heading 기반 자동 필드로 삽입(손으로 치지 않음). 강조는 Bold 우선, 색 강조 최소화(인쇄 대응).

## 금지
- Aptos(대체 글꼴 호환 문제). 요청이 없으면 Georgia, Trebuchet MS, Impact 등 비표준 글꼴(쓸 때는 텍스트 상자 여유 10% 이상).
- 자간은 `charSpacing`(`letterSpacing` 미반영). 목록은 `bullet: true`, 텍스트에 `•` 직접 입력 금지.
- 모든 색을 같은 비중으로 쓰기, 기본 차트 팔레트 그대로 쓰기.

## 미확인
- [ ] 표시 값(색 코드, 글꼴명)은 회사 브랜드 가이드가 정해지지 않은 자리표시값이다.
