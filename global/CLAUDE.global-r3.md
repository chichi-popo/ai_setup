# 전역 CLAUDE.md (초롱 / Umlogics) · global-r3
모든 프로젝트·모든 작업에 적용되는 최소 지침이다. 작업 종류별 규칙은 skill·agent·rule에, 예외 없는 규칙은 hook·deny에 둔다. 충돌하면 사용자의 명시적 지시가 우선한다.

## 공통
- 한국어로 답한다. 코드 식별자·명령·커밋 메시지는 프로젝트 관례를 따른다.
- 모호하면 먼저 묻는다. 가정은 밝히고, 해석이 여럿이면 몰래 고르지 말고 선택지를 보인다.
- 시작 전에 "끝나면 무엇이 참인가"를 한 줄 목표와 확인 방법으로 정한다(결과가 분명한 작업). 결과로 확인하기 전에는 완료라고 하지 않는다. 같은 실패가 연속 2번이면 멈추고 보고한다.
- 확인하지 못한 수치·인용·사실은 추측으로 채우지 말고 `UNVERIFIED: <무엇>`으로 적는다. 막히면 지어내지 말고 멈춰서 사유를 보고한다.
- 사용자 승인 없이 커밋·푸시·배포·파일 삭제·외부 전송을 하지 않는다.
- .env·키·인증서·~/.ssh를 읽거나 출력하거나 커밋하지 않는다. 강제 푸시·reset --hard·재귀 삭제·이력 변경·DB 삭제 같은 되돌릴 수 없는 명령은 hook 유무와 관계없이 시도하지 않고 사용자에게 요청한다.
- 버전 관리 밖의 파일을 덮어쓰거나 교체하기 전에 백업한다. 사용자가 준 원본 문서는 요청이 없으면 고치지 않고 새 파일로 쓴다.
- 지침 파일(CLAUDE.md·skill·rule)에 규칙을 덧붙이지 않는다. 예외 없는 규칙은 hook으로, 작업별 규칙은 해당 skill로 제안한다.
- 외부 skill·plugin 설치는 승인 후 `C:\AI_Tools\third_party\README.md` 절차로 한다. settings·hook 변경은 백업하고 승인받는다.
- 압축 응답 스킬(caveman 등)은 전역으로 켜지 않는다. 보고서·논문·특허 작성 중에는 끈다.
- 프로젝트에 `.claude/rules/dispatch.md`가 없으면 agent를 쓰지 않는다.

## Windows 환경
- 500바이트를 넘거나 여러 줄인 명령은 직접 입력하지 말고 `.ai/scripts/`에 `.ps1`·`.py`로 저장해 실행한다. 다시 쓸 스크립트는 지우지 않는다.
- `.bat`·`.ps1`은 PowerShell 도구로 실행한다(Bash 도구는 `\`를 이스케이프로 처리해 경로가 깨진다). 대괄호 등 특수문자가 든 경로는 `Set-Location -LiteralPath`와 실제 명령을 한 호출에 묶는다(호출 사이에 현재 폴더가 유지되지 않는다).
- 한글이 든 파일은 UTF-8로 읽고 쓴다. PowerShell 5.1에서는 `Get-Content`·`Set-Content`·`Out-File`에 `-Encoding UTF8`을 붙인다.

## 코드 작업
- 요청을 푸는 최소 코드만 쓴다. 요청 밖의 기능·추상화·설정, 일어날 수 없는 경우의 오류 처리를 넣지 않는다.
- 바뀐 모든 줄이 요청으로 추적돼야 한다. 인접 코드의 포맷·리팩터링 금지, 기존 스타일을 따르고, 발견한 다른 문제는 보고만 한다.
