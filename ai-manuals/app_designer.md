# App(모바일) UI 디자인 가이드라인 — 범용/기본값

이 문서는 신규 모바일 앱(iOS/Android) UI를 설계/구현할 때 항상 적용하는
**범용 디자인 톤앤매너 기본값**입니다. Claude는 별도 지시가 없는 한 아래 규칙을
기본값(default)으로 따릅니다. `[ ]` 표시된 항목은 회사/프로젝트 상황에
맞게 실제 값으로 채워 넣으세요.

> ⚠️ **우선순위 규칙**: 프로젝트 폴더에 `app_design_guideline.md`가 별도로
> 존재하면, 해당 문서가 이 문서보다 **우선 적용**된다. `app_design_guideline.md`가
> 명시하지 않은 항목(터치 타겟 크기, 기본 네비게이션 패턴 등)에 한해 이 문서의
> 규칙을 기본값으로 따른다.

---

## 1. 색상 (Color Palette)

- **주조색(Primary)**: `[#0F2A4A]`
- **보조색(Secondary)**: `[#5B7FA6]`
- **포인트색(Accent)**: `[#F2A93B]` — 주요 액션 버튼, 선택 상태
- **시맨틱 색상**: 성공 `[#0ca30c]` / 경고 `[#fab219]` / 오류 `[#d03b3b]`
- 다크모드 대응 시 배경/텍스트 색상 쌍을 별도로 정의(라이트: 배경 `#FFFFFF`/텍스트 `#222222`, 다크: 배경 `[#121212]`/텍스트 `#EEEEEE`)

---

## 2. 타이포그래피

| 요소 | 크기 | 굵기 |
|---|---|---|
| 화면 타이틀 | 20–22pt/sp | Bold |
| 섹션 헤더 | 17–18pt/sp | Semibold |
| 본문 | 14–15pt/sp | Regular |
| 캡션/보조설명 | 12pt/sp | Regular, 회색 |

- iOS: San Francisco(시스템 폰트) 기본 / Android: Roboto(시스템 폰트) 기본. 커스텀 폰트가 필요하면 플랫폼별 렌더링 차이(줄 간격 등)를 별도 확인.
- 플랫폼 고유 타이포 스케일(iOS Dynamic Type / Android Material Type Scale)을 최대한 따르고 임의 크기 남발 금지.

---

## 3. 레이아웃 & 터치 타겟

- 최소 터치 타겟 크기: **44×44pt(iOS)** / **48×48dp(Android)** 이상
- Safe Area(노치/홈 인디케이터) 침범 금지 — 상하단 콘텐츠는 반드시 safe area 안쪽에 배치
- 화면 여백: 좌우 16–20pt/dp 기본
- 리스트/카드 항목 간 간격: 8–12pt/dp

---

## 4. 네비게이션 패턴

- 하단 탭바(Tab Bar): 주요 메뉴 3–5개 이내, 아이콘 + 라벨 병기
- 화면 전환: 계층 이동은 스택(Push/Pop), 병렬 전환은 탭/스와이프로 구분해 일관성 유지
- 뒤로가기: iOS는 좌상단 back 버튼, Android는 시스템 back 제스처/버튼과 동일하게 동작하도록 커스텀 back 버튼 동작을 임의로 바꾸지 않는다.

---

## 5. 컴포넌트 기본 스타일

- **버튼**: 모서리 반경 8–12px, 기본 높이 48pt/dp 이상(터치 타겟 기준 충족)
- **카드**: 모서리 반경 12–16px, 그림자는 옅게
- **입력 필드**: 높이 44–48pt/dp, 포커스 시 accent 색상 테두리
- 플랫폼별 기본 컴포넌트(iOS `UIKit`/`SwiftUI`, Android `Material Components`)와 크게 어긋나는 커스텀 컨트롤은 지양(학습 비용 증가)

---

## 6. 체크리스트 (완성 후 확인)

- [ ] 모든 터치 요소가 최소 터치 타겟 크기(44×44pt / 48×48dp) 이상인가
- [ ] Safe Area를 침범하는 콘텐츠가 없는가
- [ ] 색상이 지정된 팔레트 내에서만 사용되고, 다크모드 대응이 되어 있는가(해당 시)
- [ ] 네비게이션 패턴(탭바/스택 전환/뒤로가기)이 플랫폼 표준과 일치하는가
- [ ] 폰트 크기/굵기가 플랫폼 타이포 스케일 범위를 따르는가
