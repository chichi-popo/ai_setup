# PPT 디자인 톤앤매너 (프로젝트 맞춤형)

> 이 문서는 **이 프로젝트 전용** 가이드다. 범용 규칙(캔버스 규격, 여백,
> 도형 기본 스타일, 표지/본문 다크·라이트 구성 등)은 `ppt_designer.md`를 따르고,
> **색상 역할 정의와 차트 규칙은 이 문서가 ppt_designer.md보다 우선한다.**
> 즉, 슬라이드 생성 시 이 두 문서를 함께 참고하되, 겹치는 항목(예: 색상
> 팔레트)은 이 문서의 값을 사용한다.
>
> 회사 브랜드 가이드가 따로 있으면 그쪽을 우선하고, 아래는 그게 없을 때 쓸
> 기본값(브랜드 뉴트럴)이다. **색상 슬롯 이름만 유지하고 hex만 브랜드컬러로
> 치환하면 나머지 규칙은 그대로 적용 가능.**

## 1. 색상 — 역할별로만 쓰고, 절대 섞지 않는다

색상은 4가지 역할(범주색 / 상태색 / 발산색 / 잉크색)로 엄격히 분리한다.
같은 hex라도 역할이 다르면 절대 겹쳐 쓰지 않는다.

### 1-1. 범주색 (모델/그룹 구분용)

- 고정 순서, **절대 로테이션 금지** — 슬라이드가 바뀌어도 동일 항목은 항상 동일 색.

| 슬롯 | 대상 | 색상 |
|---|---|---|
| 슬롯1 (blue) | M1 / 보정후 / Kaggle | `#2a78d6` |
| 슬롯2 (green) | M2 | `#008300` |
| 슬롯5 (aqua) | M3 | `#1baf7a` |
| 슬롯8 (red) | baseline / 보정전, 대비용 | `#e34948` |

> 한 슬라이드 안에서 같은 항목은 항상 같은 색을 쓴다.
> (예: M1은 모든 슬라이드에서 계속 blue)

### 1-2. 상태색 (채택여부 — 범주색과 절대 겹치지 않음)

| 상태 | 색상 |
|---|---|
| 채택 = good | `#0ca30c` |
| 미채택/기각 = critical | `#d03b3b` |
| 미결정/검토중 = warning | `#fab219` |

- 표4(저비용개선), 표5(ablation) "채택여부" 열에 적용.
- **아이콘 + 텍스트 병기 필수** — 색만으로 의미 전달 금지 (색약 대응).

### 1-3. 발산색 (전/후·증감 비교, 0 기준선 있는 delta 차트)

| 방향 | 색상 |
|---|---|
| 양의 방향 | blue |
| 음의 방향 | red |
| 중립 | 회색 `#f0efec` |

- ablation delta 차트, calibration 전후 차이 표현에 적용.

### 1-4. 잉크색 (텍스트 전용)

| 용도 | 색상 |
|---|---|
| 본문 | `#0b0b0b` |
| 캡션/보조설명 | `#52514e` |
| 축/눈금 | `#898781` (회색, 존재감 낮게) |

- **수치 라벨은 절대 범주색 그대로 쓰지 않고 잉크색을 유지** (옆의 마크/범례가 항목 정체성을 담당).

## 2. 차트 원칙

> 모든 차트·표는 **편집 가능한 네이티브 객체**로 작성한다(이미지 삽입 금지).
> 도식화 시 값·라벨 누락 여부를 더블체크하고, 부득이한 누락은 사용자에게 보고한다.
> — 상세 원칙은 `ppt_designer.md`의 "차트·표 — 편집 가능한 형태로 작성" 섹션 참조.

### 2-1. 1축 원칙 (중요, 위반 금지)

- **이중축(다른 스케일 두 지표를 한 차트에) 절대 금지.**
- ⚠️ **Slide 4-2 스펙 수정 필요**: 원안의 "보조축에 Brier score" 표현은 이중축 위반.
  → accuracy 막대차트와 Brier score 막대차트를 **별도 두 차트로 분리**해 나란히 배치할 것.

### 2-2. 막대 차트

- 막대는 얇게, 데이터 끝은 4px 라운드.
- 막대 사이 최소 여백 확보.
- **범례**: 계열 2개 이상일 때만 노출 (1개면 제목이 범례를 대신함).
- **4개 이하 계열**: 막대 위 직접 라벨 병기 (값이 한눈에 보이도록).
- **95% CI**: 에러바(whisker)로 표시, 막대와 색으로 구분(잉크색 사용).

### 2-3. 그리드라인

- 아주 옅게(연한 회색 `#e1e0d9`) 처리 — 시각적으로 죽여서 데이터가 주인공이 되게.

---

## 3. 타이포그래피 & 레이아웃

- **폰트**: 전체 sans-serif 하나로 통일 (맑은 고딕 / Segoe UI 계열).
- **표 숫자**: 정렬용 tabular figure(고정폭 숫자) 사용.
- **제목**: 위치·크기 전체 슬라이드에서 통일.
- **Footer**: 우하단에 슬라이드 번호 + 문서버전 고정 표기.
- **배경**: 밝은 중성색(`#fcfcfb` 류) 하나로 통일 — 슬라이드마다 배경 바꾸지 말 것.

---

## 4. 체크리스트

- [ ] 범주색이 모델/그룹별로 고정되어 있고 슬라이드 간 로테이션되지 않았는가
- [ ] 상태색(채택여부)이 범주색과 겹치지 않고, 아이콘+텍스트가 병기되었는가
- [ ] delta/증감 차트에 발산색(blue↔red, 중립 회색)이 적용되었는가
- [ ] 수치 라벨이 범주색이 아닌 잉크색으로 표기되었는가
- [ ] 한 차트에 이중축(다른 스케일)이 사용되지 않았는가 (Slide 4-2 분리 반영)
- [ ] 막대 끝 4px 라운드, 얇은 막대, 충분한 막대 간 여백이 적용되었는가
- [ ] 범례는 계열 2개 이상일 때만 표시했는가 / 4개 이하 계열은 직접 라벨 병기했는가
- [ ] 95% CI가 에러바로, 그리드라인이 옅은 회색(`#e1e0d9`)으로 처리되었는가
- [ ] 폰트가 sans-serif 하나로 통일되고, 표 숫자에 tabular figure가 적용되었는가
- [ ] 제목 위치/크기, footer(슬라이드 번호+문서버전), 배경색이 전체 슬라이드에서 통일되었는가
