# Web UI 디자인 가이드라인 — 범용/기본값

이 문서는 신규 Web(반응형 웹) UI를 설계/구현할 때 항상 적용하는
**범용 디자인 톤앤매너 기본값**입니다. Claude는 별도 지시가 없는 한 아래 규칙을
기본값(default)으로 따릅니다. `[ ]` 표시된 항목은 회사/프로젝트 상황에
맞게 실제 값으로 채워 넣으세요.

> ⚠️ **우선순위 규칙**: 프로젝트 폴더에 `web_design_guideline.md`가 별도로
> 존재하면, 해당 문서가 이 문서보다 **우선 적용**된다. `web_design_guideline.md`가
> 명시하지 않은 항목(브레이크포인트, 기본 컴포넌트 스타일 등)에 한해 이 문서의
> 규칙을 기본값으로 따른다.

---

## 1. 색상 (Color Palette)

- **주조색(Primary)**: `[#0F2A4A]`
- **보조색(Secondary)**: `[#5B7FA6]`
- **포인트색(Accent)**: `[#F2A93B]` — CTA 버튼, 강조 링크
- **시맨틱 색상**: 성공 `[#0ca30c]` / 경고 `[#fab219]` / 오류 `[#d03b3b]` / 정보 `[#2a78d6]`
- **배경/텍스트**: 배경 `#FFFFFF`(라이트) / 본문 텍스트 `#333333`, 보조 텍스트 `#666666`

---

## 2. 타이포그래피

| 요소 | 크기(desktop) | 크기(mobile) | 굵기 |
|---|---|---|---|
| H1 | 32–40px | 24–28px | Bold |
| H2 | 24–28px | 20–22px | Bold |
| Body | 16px | 15px | Regular |
| Caption | 13px | 12px | Regular, 회색 |

- 웹폰트: `[Pretendard]` 또는 시스템 폰트 스택(`-apple-system, Segoe UI, sans-serif`)
- 줄 길이(가독성): 본문 텍스트 컨테이너 최대 폭 65–75자 수준으로 제한

---

## 3. 레이아웃 & 반응형 브레이크포인트

- 브레이크포인트: `mobile < 768px` / `tablet 768–1023px` / `desktop ≥ 1024px`
- 그리드: 12컬럼, gutter 16–24px, 컨테이너 최대 폭 `[1200px]`
- 콘텐츠 블록 간 간격(section spacing): 48–96px(desktop), 32–48px(mobile)

---

## 4. 컴포넌트 기본 스타일

- **버튼**: `border-radius` 6–8px, primary/secondary/ghost 3종 기본, 최소 높이 40px
- **카드**: `border-radius` 8–12px, 그림자는 옅게(`0 2px 8px rgba(0,0,0,0.08)`)
- **폼 요소**: 입력창 높이 40–44px, 포커스 시 accent 색상 outline 표시
- **아이콘**: 24px 기준 그리드, 선/면 스타일 혼용 금지(하나로 통일)

---

## 5. 접근성 (Accessibility)

- 텍스트 대비율 WCAG AA 기준(본문 4.5:1, 큰 텍스트 3:1) 이상 확보
- 모든 인터랙티브 요소에 포커스 상태(outline/box-shadow) 표시, `outline: none`만 적용 금지
- 색상만으로 상태를 구분하지 않고 아이콘/텍스트 병기(색약 대응)

---

## 6. 체크리스트 (완성 후 확인)

- [ ] 색상이 지정된 팔레트(주조/보조/포인트/시맨틱) 내에서만 사용되었는가
- [ ] 브레이크포인트별 레이아웃이 깨지지 않는가(mobile/tablet/desktop)
- [ ] 버튼/카드/폼 요소가 기본 스타일 규칙을 따르는가
- [ ] 텍스트 대비율과 포커스 상태가 접근성 기준을 충족하는가
- [ ] 폰트 크기/굵기가 규정된 범위를 따르는가

---

> 💡 이 문서의 `[ ]` 항목(색상 코드, 폰트명, 브레이크포인트 값)은 회사 브랜드 가이드나 프로젝트 톤에 맞춰 교체해서 사용하세요.
